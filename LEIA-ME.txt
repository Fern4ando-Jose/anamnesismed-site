  - DB: alter table profiles -> trial_end agora tem default 'now() + interval 30 days' (cobre inserts futuros fora do app); rodado backfill para perfis antigos sem trial_end (não havia nenhum afetado).
  - DB: criado manualmente o registro de perfil que faltava para o usuário fernando-jose@outlook.com.br (id a52339cb-ee38-42c5-b14b-d642eb9399b5), com plano='trial' e trial_end=2026-07-07.
  PENDENTE: enviar a alteração de supabase-integration.js (git add -A; git commit -m "fix: corrige criação de trial de 30 dias no cadastro de perfil"; git push) — sem isso, novos usuários continuam vulneráveis ao mesmo bug.
