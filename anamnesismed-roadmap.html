▲ Vercel (recomendado)
  • Cria conta em vercel.com com GitHub
  • Cria repositório GitHub: anamnesismed-site

Grátis para começar
🌐 Domínio
  • Comprar anamnesismed.com em Namecheap ou GoDaddy
  • Custo: ~$12/ano
  • No Vercel: Settings → Domains → adicionar o domínio
  • Configurar DNS no registrador (2 registros CNAME)
  • HTTPS automático via Let's Encrypt
~$12/ano
2 🔐
Autenticação real
Supabase — magic link de verdade, sem senha
Esta semana
⚡ Supabase Setup
  • Cria conta em supabase.com
  • New Project → nome: anamnesismed
  • Ir em Authentication → Providers → Email
  • Habilitar Magic Link (desabilitar senha)
  • Copiar SUPABASE_URL e ANON_KEY
Grátis até 50k usuários/mês
💻 Código a adicionar
  • Instalar SDK: supabase-js via CDN
  • Na tela de login: chamar supabase.auth.signInWithOtp({email})
  • Usuário recebe email com link real
  • Ao clicar, Supabase autentica e redireciona para o dashboard
  • Salvar sessão com supabase.auth.getSession()
  • Proteger dashboard: redirecionar se não autenticado
~2h de desenvolvimento

Supabase PostgreSQL — HCs salvas por usuário

📊 Tabelas necessárias
  • users — id, email, nome, faculdade, ano, plano, trial_end
  • historias_clinicas — id, user_id, motivo, especialidade, dados (JSON), criado_em, atualizado_em

PostgreSQL grátis no Supabase
🔒 Row Level Security
  • Cada usuário só vê suas próprias HCs
  • Supabase tem RLS nativo — 2 linhas de SQL
  • user_id = auth.uid() em todas as queries
  • Sem backend próprio necessário
